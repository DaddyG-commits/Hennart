# Hennart

Henna Art Canada — quality organic henna, body art supplies, and natural hair dye.

Established 2007 in Edmonton, AB by Nitasha. Continued in 2023 by Karelia in Victoria, BC.

## Stack

- Next.js 14
- Tailwind CSS
- Neon + Prisma
- Vercel

## Local setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

- `npm run dev` — development
- `npm run build` — prisma generate + next build
- `npm start` — production server
